# JP Clothing Backend

Backend only for the existing JP Clothing React project.

## Setup
1. Install Node.js.
2. Copy `.env.example` to `.env` and update values.
3. Make sure MongoDB is running (local MongoDB or use a MongoDB Atlas URI).
4. Run:
   npm install
   npm start

Server: http://localhost:5000

The existing frontend can call this backend through its API base URL.
